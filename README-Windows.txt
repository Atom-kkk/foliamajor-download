Folia Download 0.8.4  Windows x64 绿色版
================================================

一、怎么运行
  1. 把整个文件夹解压到任意位置（不要在压缩包里直接双击，也不建议放 C:\Program Files）。
     路径里可以有中文，程序内部按 UTF-8 处理路径。
  2. 双击文件夹里的「Folia Download.exe」。

二、首次运行被 Windows 拦下来
  这个包没有代码签名证书，Windows 会提示「Windows 已保护你的电脑」：
    点「更多信息」→ 再点「仍要运行」即可，只需要这一次。
  SmartScreen 报「已阻止可能不安全的文件」时同样点「仍要运行」。
  杀毒软件可能对未签名 exe 报警，属于误报。

三、卸载
  绿色版，直接删掉整个文件夹就卸干净了。
  用户数据（配置、缓存、登录态）在 %APPDATA%\Folia 与 %LOCALAPPDATA%\Folia，
  需要一并清掉时手动删除这两个目录。

四、这个包包含什么
  - 全部音源（网易云 / QQ / 酷狗 / 酷我 / 汽水 / 波点 / 星海 / Spotify / 自定义 / 聚合搜索）
  - 付费 / 会员歌兜底换源（先问本平台，实测是不是片段，确定放不出来才换）
  - 桌面端下载（主进程直接落盘，可选音质与目录）
  - 游客模式（未登录也能搜索、播放、看公开推荐）
  - 可视化器「按句随机」样式（每 N 句换一次）
  - 本地 ffmpeg（转码、格式转换可用）
  - MNN 分析运行库与节拍 / 分轨模型（节拍分析、BPM、和弦、分轨可用）
  - Steam Audio（声场/房间音效）
  - Apple Music 宿主（WebView2 组件随包，需要系统已装 WebView2 Runtime）
  - Spotify 播放组件（win32-x64 原生库）

五、0.8.4 修了什么

  1) 会员歌只放 1 分钟、且没有「试听」提示
     平台给的 60 秒试听地址，字节数超过了按 48 kbps 算的整首下限（4 分钟的歌
     1.44 MB，60 秒 320 kbps 有 2.4 MB），片段判定的第一道据此错判成「整首」，
     能识破的那一道根本没跑。现在字节只用于确诊片段，判不出来一律再量真实时长。

  2) 换源拿不到完整版时，多了一条「网易云同曲」的路
     实测：星海对 QQ 源已经要认证（403），酷我的曲库里常常没有某些歌的原版
     （「偏爱 / 张芸京」前 20 条全是 Live / cover / 改编）。但同一首在网易云有，
     而星海换网易云的地址仍然免费。所以前三步都失败时，会去网易云搜同一首、
     再用星海换址。这一步对 QQ、波点、Spotify 的会员歌同样生效。
     门槛不变：排除伴奏 / Live / 翻唱等版本，标题+歌手+时长够像才用，实测不是片段才交给播放器。

  3) 繁体歌名匹配不到简体曲库
     平台的曲目名可能是繁体（Spotify 的「說好的幸福呢」），而网易云、酷我的曲库存的是
     简体。旧版本搜索能搜到，但标题比对给 0 分，于是判定「没有同一首」。现在搜索与比对
     前先把歌名、歌手转成简体（opencc，按需加载）。

  升级后首次启动会清一次旧的音频缓存：之前被当成整首存下的试听片段，
  不重取就会一直只有一小段。

六、和 macOS 版的差异
  - 没有 macOS 壁纸 / 桌面歌词贴桌面那套功能（Windows 只有壁纸助手 exe）。
  - 没有触控板 / Stage Manager 相关的点击守卫。
  其余播放、搜索、下载、歌词、可视化、分析能力一致。

七、仍然只有一小段时
  按 Ctrl+Shift+I 打开开发者工具，Console 里过滤 "Fallback"，能看到每一步的结果。
  - 「所有候选都没给出完整版」+「网易云里也没有足够像的一首」：这首歌在几个曲库里
    都没有可用的原版，属于外部资源问题。
  - Spotify 的歌：非会员本来只给 30 秒试听，靠上面的换源兜底；曲库里没有同名原版时无法绕过。
  - 个别歌仍是旧行为：命令面板执行「Clear cached audio and reload」重取一次。

八、常见问题
  - 打开后白屏 / 卡在启动画面：确认解压完整（resources\app.asar 约 118MB），
    并检查是否被杀软隔离了 dll。
  - 无法播放本地文件：检查设置里的音乐库目录是否有读取权限。
  - 更新：本包不会自动更新，替换为新版本文件夹即可，用户数据保留。
